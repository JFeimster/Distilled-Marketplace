# Route map

The generated route contract is [`CANONICAL-SITEMAP.txt`](../CANONICAL-SITEMAP.txt). Its count follows the catalog; it is not a target to fill.

| Route family | Current behavior |
| --- | --- |
| `/` | Discovery hero, search, category groups, deterministic stack finder, collections, method and cross-property handoffs |
| `/directory` | Query and facet filtering with URL state, sort, reset, zero state and source status |
| `/categories` and `/categories/[slug]` | Editorial taxonomy and 16 distinct category decision pages |
| `/collections` and `/collections/[slug]` | Four practical, ordered category stacks |
| `/compare` | Evidence-gated comparison workspace with optional fictional demo |
| `/deals` | Current source-gated empty offer state |
| `/about`, `/disclosures`, `/submit` | Method, commercial disclosure and informational intake policy |
| `/providers/[slug]` | Renderer for future verified catalog records; unknown slugs return 404; no current provider routes |

Curated `/compare/[slug]`, alternatives and review pages are withheld until genuinely sourced records warrant them. Unknown routes return 404. The directory is part of this app and catalog, not a second property.
